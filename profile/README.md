## What We Build

United Data Group brings together projects across software development, automation, data, APIs, and infrastructure.

Our repositories include both experimental projects and actively developed software.

### Projects

| Project               | Description                                                                       |
| --------------------- | --------------------------------------------------------------------------------- |
| **CloudText**         | SMS gateway and developer tools for connecting applications with Android devices. |
| **VScribe**           | Video transcription API for converting speech from video into text.               |
| **Luna**              | Automation and utility projects.                                                  |
| **IMS**               | Inventory management system.                                                      |
| **30 Days of Python** | Python learning and development exercises.                                        |

> Explore all projects in the organization's [repositories](https://github.com/United-DG?tab=repositories).
